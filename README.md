# Breitling Avenger Seawolf Titanium (Ref. E17370)
### 3D Interactive Horological Simulation & Calibre 17 Architecture

A standalone Three.js and WebGL mechanical simulation of the Breitling Avenger Seawolf diver's watch, featuring procedural PBR texturing and an exploded-view breakdown of the chronometer-grade Breitling Calibre 17 (ETA 2824-2 architecture).

---

### Features
* **14-Layer Z-Axis Exploded View:** Smoothly separates the domed sapphire crystal, titanium bezel with 4 rider tabs, cobalt dial, calendar disc, gear train, and caseback while maintaining continuous operation.
* **Authentic 4Hz (28,800 vph) Regulating Organ:** Animated Glucydur balance wheel, breathing Nivarox flat spiral hairspring, and snapping Swiss lever pallet fork.
* **8-Step Chronometer Sweep:** The second hand advances in authentic 1/8th-second increments synced to real local time (`Date.now()`).
* **Raycast Component Inspection:** Hover over any internal bridge, jewel, or escapement part to inspect its horological role, materials, and tolerances.
* **Zero Asset Overhead:** Built entirely in a single file with procedural canvas textures—no external `.obj` or `.gltf` 3D files required.
